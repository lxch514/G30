# camera0 四周参考线使用说明

功能实机验证：2026-10-19；最终源码与 APK 整理：2026-10-20。APP v1.2.0，包名 g30.sixcamera.app。

## 已实现

只在 camera0 上叠加一圈黄色参考框、红色角标和轻微的框外暗色遮罩；camera1～5 的画面不叠加参考线。参考框按实际视频图像计算位置，跟随黑边和宽高比，六宫格及单路全屏使用同一组位置比例。

默认左、右边距各为图像宽度的 12%，上、下边距各为图像高度的 15%。这是演示用的初始位置，不代表机器人尺寸、真实距离或已经标定的安全范围。红色角标用于突出边界，不代表程序已经发现危险物体。

## 操作

点击顶部“参考线”，或长按 camera0，打开设置。设置期间自动将 camera0 放大；关闭后回到打开设置前的布局。

上下左右可以独立调节，各为 0～40% 的图像边距。拖动时即时预览；“保存”记住位置和显示开关，重启 APP 后继续使用；“取消”或返回键恢复进入设置前的值。“恢复默认”恢复初始位置，仍需点击“保存”确认。

调整参考线、打开设置和切换全屏均只改变 APP 显示，不重启板端、不改 USB 额度，也不重连 TCP 视频。只有 camera0 全屏时保留参考线按钮，其他单路全屏保持原来的显示方式。

位置保存在 G30 本机 APP 的 SharedPreferences（guide0.enabled/left/top/right/bottom）中，不写板端配置。普通升级使用 install -r 可保留位置和连接地址；卸载 APP 会清除这些设置。

## 功能边界

画面标有“参考线·非测距”。本版本不输出米数、不识别障碍、不自动判断物体越线，也不触发机器人动作；操作者根据画面和参考线人工判断、干预。

真实空间中不同深度的物体可能落在同一条图像线上，靠近线条不等于距离机器人相同。若后续需要厘米数或自动警示，需要另外建立墙面几何标定或接入测距数据，并明确适用的平面和观察方向。

最终源码中，若 camera0 长时间没有新显示帧，参考线改为灰色并提示“无实时画面”；不会仅因状态 HTTP 暂时失败就把仍在更新的视频标成停滞。此离线提示逻辑的最后微调已经构建通过，2026-10-20 因 G30 暂未连接 ADB，最终 APK 尚未补装。
