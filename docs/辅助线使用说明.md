# camera0 / camera1 辅助线说明（APP v1.3.0）

更新日期：2026-10-20。项目 /root/G30；包名 g30.sixcamera.app，版本号 4。

## 使用方法

六宫格顶部点击“参考线”，选择 camera0 或 camera1；也可以直接长按对应画面。设置时自动放大目标通道，关闭设置后回到之前的布局。camera0、camera1 全屏时，顶部按钮直接编辑当前通道。其他四路不添加辅助线。

- camera0：保留原来的四周黄色边界、红色角标和轻微框外遮罩。默认左右边距各 12%、上下边距各 15%，四边可独立调节 0～40%。
- camera1：两条平行横线，上红、下黄。默认红线在图像从上往下 70% 的高度，黄线在 85%，共同左右边距各 5%。红线高度可调 0～99%、黄线高度 1～100%，会自动阻止交叉，至少相隔图像高度的 1%。共同左右边距可分别调节 0～40%，横线始终平行。

位置按实际视频图像的比例计算，六宫格和全屏使用同一组参数，黑边不参与计算。每路可以单独开关、恢复默认。“恢复默认”只做预览，需要点击“保存”；“取消”或返回键放弃本次修改。

## 保存和重新上电

两个通道的位置和显示开关分别写入 G30 APP 的私有 SharedPreferences（g30-sixcam），不是写进板端 run 目录。camera0 沿用 guide0.enabled/left/top/right/bottom，保留旧版已保存的值；camera1 使用 guide1.enabled/left/red/right/yellow。

点击“保存”后，APP 显示“保存中…”，在后台执行 commit()；确认存储写入成功后才关闭设置窗口。失败会显示提示并允许重试，不把失败当作已保存。重新打开 APP 时分别读取两路设置。

因此在正常存储工作条件下，保存完成后，即使开发板和遥控器都断电再开机，也会保留最新设置。只给板子重新上电不会影响遥控器本地参数。卸载 APP、清除 APP 数据或恢复出厂设置会删除这些参数；普通升级应使用 adb install -r 覆盖安装，不要先 uninstall。

## 实现在哪里

- remote/android/app/src/main/java/g30/sixcamera/app/CameraGuideView.java：在解码视频表面上绘制 camera0 边界或 camera1 双横线；掉帧停滞后改为灰色并提示“无实时画面”。
- 同目录 GuideConfig.java：各通道默认值、比例范围、红线在黄线上方的约束。
- 同目录 MainActivity.java：通道选择、设置滑块、保存/取消/恢复默认、读取和持久化。
- 同目录 CameraTile.java：把叠加层放到 camera0/1 的真实图像区域，跟随六宫格/全屏变换。

辅助线完全在遥控端 APP 中绘制，不改变板端摄像头画面、编码、码率或 TCP 数据。位置调整和全屏切换不主动重连视频。

## /root/G30/run 是什么，能否删除

它是运行临时目录，不是 APK 截图目录。run/frames 是启动时挂载的内存 tmpfs，用于在采集和编码之间交换最新 JPEG；*.pid 是进程编号，start.lock 是启动锁，health.json 是运行检查结果。validation 和其他测试状态 JSON 是此前调试的记录。

2026-10-20 已确认本项目服务未运行、run 下没有挂载、启动锁无人持有，才清理了旧的临时内容，保留空 run 目录。清理约 109KiB，没有删除源码、配置、日志或已有 APP 设置，也没有重新启动采集。

以后停止服务并卸载 run/frames 后，旧临时内容可以清理；程序启动会重建所需文件。正在采集时不能直接删除 run/frames、PID 或锁文件。需要重新开始图传时仍执行 bash /root/G30/scripts/start.sh。

## 后续安装（CMD）

在下载的 APK 所在目录执行，无需重新编译：

```bat
adb devices
adb install -r g30-sixcamera-debug.apk
adb shell am force-stop g30.sixcamera.app
adb shell am start -n g30.sixcamera.app/.MainActivity
```

这些线仅供操作者人工观察，不测量真实距离，不识别物体、不自动判断越线或触发机器人动作。红黄颜色不会随距离自动变化。
