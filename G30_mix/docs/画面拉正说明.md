# camera3 + camera4 画面拉正

2026-10-20，程序位于开发板 `/root/G30_mix`，已应用并启动。原 `/root/G30` 六路采集、H.264传输和APK保持原样。

## 怎么看、怎么调

1. 电脑打开或刷新 <http://192.168.1.239:8097/>；G30浏览器可访问 <http://192.168.144.10:8097/>。本次更新的是网页拼接试验，不需要重装APK。
2. 展开“画面拉正”。当前选择 **camera3为基准**，旋转微调 **-0.16°**，勾选“裁掉黑边”。此配置输出 **1583×537**，目标8帧/秒。
3. 相机安装角度变化时，可点“自动拉正并保存”。程序参考门框等较长竖线估算旋转角，只计算并保存一次，避免每帧角度跳动；没有足够可靠线段时会提示失败，并保留上次设置。
4. 需要手动调整时，选择camera3、camera4或原始居中视角；移动角度滑块，点击“应用微调并保存”。正角度按OpenCV图像旋转约定为逆时针，负角度为顺时针，可按预览微调。
5. 勾选“裁掉黑边”可去除两路均未覆盖的边缘；取消可检查完整覆盖范围。“恢复原始完整视角”恢复居中投影、零旋转、保留黑边，也会保存。

裁剪会减少上下及边缘视野。`samples/level-input/comparison.jpg` 用同一对原始图比较处理前后：上图为原始居中拼接，下图为当前拉正和裁黑边后的结果。近处桌沿仍可能有视差接缝。

## 保存在哪里

板子重新上电后手动启动：

```bash
bash /root/G30/scripts/start.sh
bash /root/G30_mix/scripts/start.sh
```

只重启拼接预览：

```bash
bash /root/G30_mix/scripts/stop.sh
bash /root/G30_mix/scripts/start.sh
```

## 这次处理的作用

用camera3的原始视角作为基准，把camera4映射到同一视角，再对整幅画面做小角度旋转；根据有效覆盖区域裁黑边。几何变换和裁剪合并到每路的固定映射中，实时画面只重采样一次。原始居中视角仍可随时恢复。

这解决了拼接投影造成的部分倾斜和不规则边框，但**尚未做镜头畸变标定**。没有测得焦距、光心及径向/切向畸变参数，不保证所有方向的线同时水平或垂直；真实透视、镜头弯曲及近景视差仍可能保留。后续有棋盘格后再分别标定两台镜头，并重新检查拼接关系。
